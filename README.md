# 思序 · Sixu

一个供个人使用的长文章创作工具：从选题和对话开始，梳理经历与观点，确认大纲后再写作。

> **开发中，主要在 Windows 本机验证。** 基于 [NoteGen](https://github.com/codexu/note-gen) v0.39.2 定制，不是从零开发，也不是 NoteGen 官方发行版。保留上游版权，采用 [GPL-3.0](LICENSE)。

## 为什么做

写长文章时，困难常常发生在动笔之前：想写什么、自己的观点是什么、有哪些真实材料。思序希望先帮助使用者把这些问题聊清楚，再进入正文。

## 当前能够做什么

- 创作台提供推荐选题、聊近况、大纲、全文、逐节写作和配图建议入口。
- 按钮准备消息，由使用者检查后发送，不自动改写文件。
- 本机保存创作方向、读者、表达习惯和避免事项，在后续请求中使用。
- 通过上游已有的模型服务设置，连接自己的 API 服务；已实际验证 DeepSeek 对话。
- 沿用 NoteGen 的 Markdown 编辑器和对话能力，完成过一次“讨论 → 选择切入点 → 确认大纲 → 生成一节 → 修改 → 保存 Markdown”的实际使用。
- 修复了流式中文跨字节分块乱码、用户模型配置启动加载、未配置嵌入模型时后台反复提示等问题。
- 为消息和会话条目增加一致性保护，以及针对缺失会话入口的保守恢复。

“先聊再写”和“大纲确认”目前主要通过提示词引导，尚未实现严格的逐篇状态约束。上游提供的其他能力不等于已经全部在思序中验收。

## 本地开发

需要 Node.js 24、pnpm 11。桌面端另需 Rust、Windows C++ 构建工具和 WebView2。其他平台继承了上游代码，尚未在本定制版验证。

```sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
pnpm build
pnpm exec tauri dev
```

仓库沿用上游 Rust 1.88.0 声明；本机成功构建使用 stable 1.99.1。Windows 如需使用已安装的 stable，可在当前 PowerShell 设置 `$env:RUSTUP_TOOLCHAIN='stable'`，不需要把个人工具链路径写进代码。

构建开发版可执行文件：

```sh
pnpm exec tauri build --debug --no-bundle
```

开发版可能附带控制台窗口。详细检查见 [开发和验证说明](project-docs/DEVELOPMENT.md)。

## 模型与数据

API Key 由使用者在应用模型设置中填写，本仓库不提供模型服务或内置额度。普通对话不要求配置嵌入模型；嵌入模型用于语义索引等能力。

文章和配置保存在本机应用数据目录。调用在线模型时，请求会发送所选上下文和写作偏好给配置的服务商；本机保存不代表所有推理都离线。不要提交密钥、配置导出、数据库、私人对话或日志。首次使用和更新前建议自行备份重要资料。

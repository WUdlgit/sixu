# 隐私与发布范围

本仓库只发布源码、许可证、开发说明和无私人数据的检查。个人数据库、文章、对话、OCR 书籍、日志、凭据、环境文件、构建产物及本机工具链不属于发布内容。

维护提交使用 GitHub noreply 邮箱。首次发布使用独立源码快照，保留上游版本、版权、许可证和来源说明，不携带本机开发目录的 Git 配置或私人历史。

发布前已检查候选文件、Git 暂存内容及提交元信息：服务密钥常见格式、本机用户名/私人邮箱/手机号、绝对个人路径，以及数据库/日志/环境文件。上游自带的服务凭据已移除。

文本模式扫描不能保证发现所有形式的敏感信息。不要在 Issues、截图、终端日志或未来提交里粘贴凭据及私人聊天。API Key 在模型设置中输入，不写入源码。应用本地凭据存储的安全性没有做完整审计；使用个人电脑账户访问控制保护本机文件。
